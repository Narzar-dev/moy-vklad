# Мой опыт

Локальный Expo MVP для Android: ребёнок выполняет до трёх безопасных дел в день, честно отмечает уровень помощи, получает опыт с дневным лимитом и может добавить инициативу. Родительский режим показывает нейтральный обзор без оценок и сравнений.

## Запуск

```powershell
npm install
npm run android
```

Для тестов и статической проверки:

```powershell
npm test
npm run typecheck
```

## Что реализовано

- Expo Router / TypeScript, конфигурация Android (`ru.moyvklad.app`);
- адаптивный детский интерфейс с крупными карточками и accessibility labels;
- правила XP: стадии освоения, бонус максимум 5 XP, лимит 50 XP в день;
- переходы `learning → practice → independence_check → graduated`;
- выбор максимум трёх незавершённых задач по приоритету и времени;
- грамматически полные русские мужские/женские фразы;
- unit-тесты XP, освоения, отбора карточек и текстов.

Это интерактивный локальный MVP. Шифрованная SQLite-база, биометрический gate, уведомления, экспорт и полноценный onboarding предусмотрены планом, но потребуют добавления Expo-native модулей и development build.
